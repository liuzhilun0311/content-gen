# 手动默认设置

## 首次使用告知

读取实际执行技能的 [config/extend.md](../config/extend.md)，通过 `preferences.py` 校验，再由 `task_parameters.py` 将默认值映射成任务表。在会话简短说明当前起点、视觉偏好、生图选择、模型、数量、输出及审核设置，采用与任务表一致的实际值。没有默认的条件参数只说明按任务补充，不编造值。

提供实际 `config/extend.md` 的绝对路径链接。告知：“全部参数说明、选项和默认值都在这份配置中。长期默认修改 JSON 的 defaults；空字符串表示没有默认值，null 表示明确使用服务默认。任务中的选择不会自动修改默认设置。”

这是告知，不是初始化问卷。不另建默认填写副本，不要求逐项回答、确认已看过或保存默认设置。没有调整要求时继续任务；已告知过时不反复说明。用户正在修改配置时，继续不依赖这些参数的阅读和分析；修改完成后重新读取并检查条件和兼容性。

## 配置文件

版本3的 JSON 只包含 `version` 和 `defaults`。`defaults` 保存全部用户参数默认值，包括起点、是否使用 image-gen、六个输出及两个审核开关。参数表格列出说明及编号选项，第三、四列保持空白，不重复维护默认值。名称和专业领域必须每个任务单独填写，不能设置跨任务默认。说明文字不是执行指令。

`preferences.py` 不接收任务答案、不累计任务选择，也不自动补建缺少的默认值。默认值只能由用户手动修改，或按用户明确指定的值修改配置。某次任务选了一个值，甚至连续多次选择相同值，都只影响这些任务。

读取和校验：

```text
python "<技能绝对路径>/scripts/preferences.py"
```

缺少 `config/extend.md` 时，生成新任务表使用 `config/extend.example.md` 的出厂配置，不写文件。需要初始化或迁移配置时显式运行：

```text
python "<技能绝对路径>/scripts/preferences.py" --migrate
```

兼容旧安装：新路径不存在时读取根目录 `extend.md`；两个文件都存在时只读取新路径，不合并。版本1、2的默认值可继续读取，旧的统计元数据不参与执行。显式迁移到版本3时保留已有默认值，移除已废弃元数据及参数行。普通读取、校验、生成任务表不会修改原文件。示例文件只用于初始化和稳定编号校验，不作为第二个日常配置入口。

文件格式错误时保留原文件并请求修正，不默默清空或使用猜测值。Python 不可用时说明当前校验工具不可用，保留配置并核对本次参数，不报告已完成校验。

## 任务快照

按 [parameter-rules.md](parameter-rules.md) 生成五列任务表。第三列保存生成时的默认快照，第四列保存本次明确选择。明确选择优先，其次为本任务已展示的兼容默认；适用参数没有值时集中澄清。用户选填空白不视为明确回答，必填空白、工具无回答或超时也不构成沿用授权。

后续修改全局默认只影响新表，不追溯修改已保存任务。用户明确要求当前任务采用新设置时，更新当前任务参数并处理下游失效。旧任务表里已移除的参数行保留原文，但不参与执行、不产生全局配置写入。

选项编号固定，不按默认值或推荐顺序重排。宿主强制“推荐”标签时仍明确区分默认值和内容分析建议，不把建议当成用户答案。条件不满足的参数不发送；默认参考图策略不授权使用其他任务文件。预设、参考用途、透明背景、格式和模型能力仍须按实际任务检查，冲突时先澄清。

## 字段与隐私

字段使用配置表中的英文标识，无英文标识的参数使用中文名称；`use_image_gen` 对应“是否使用 image-gen”。水印采用扁平键 `watermark.enabled/content/position`。开关为布尔值，数量为整数。空字符串或缺少键表示没有默认值；明确选择服务默认的可选参数为 `null`，支持范围仍由参数校验确定。

参考图、输出目录、讲义保存及数量约束只保存策略；实际路径、参考文件、预算金额和收费授权在本次任务中提供。非敏感水印作者名称及自定义视觉偏好可以手动保存；专业领域规范不能写成视觉默认。参数与开关规则见 [illustration-settings.md](illustration-settings.md) 和 [workflow-switches.md](workflow-switches.md)。

`extend.md` 是私有配置，不进入课程成品或公开技能包。`config/.env` 仅读取 `SANBAO_NODE`、`SANBAO_MARKED`、`SANBAO_PLAYWRIGHT`、`SANBAO_BROWSER` 四个工具路径，环境变量优先，空值自动发现。生图服务和密钥由实际生图工具管理，不读取或迁移遗留生图凭据。不得将密钥、账号密码、正文、审核授权或支付信息写入默认值。分享包仅包含配置示例。
