# 作图参数选择与确认

所有适用参数记录在本任务 `<任务名称>_参数.md`，可由用户填写文件或将工具、会话答案映射回编号选项。表格规范和起点选择见 [parameter-rules.md](parameter-rules.md)，完整参数目录与全局默认统一在 [config/extend.md](../config/extend.md)。按 [default-settings.md](default-settings.md) 在生成新表时映射 JSON 默认；不覆盖已生成任务快照，不视为本次明确回答。已选值不重复问，选填空白且有兼容默认时无需另行确认。

## 交互规则

- 按 [user-interaction.md](user-interaction.md) 统一选择提问工具、备用形式及合并方式。无工具时在宿主允许的范围内发送编号问题，否则使用参数文件和允许的直接确认形式。
- 先交付五列编号参数文档，供用户编辑第四列。默认只在第三列显示，不改变第五列的选项顺序。需要会话选择或补充澄清时优先用内置输入工具并同步答案，不能用工具的显示序号覆盖文档编号。
- 遵守工具限制。工具最多支持三个问题时按轮拆分；每题仅支持两到三个选项时，优先呈现有效默认值及适用替代值，其他值通过工具自带的自定义入口收集。工具自动提供“其他”时不要重复添加。
- 独立问题可合并；先解析预设及独立覆盖值，再检查展开组合。先确定参考图再补齐用途，先确定格式再检查压缩，先确定水印开关再补齐文字与位置。已具有有效值的项目不重复提问。
- 身份答案缺失、适用参数没有答案或可用默认、条件补充缺失时保留待回答状态并停止依赖阶段。用户选填项空白且具有兼容默认时继续执行；不能在仍等待必要答案时调用画图服务。
- 自定义内容是必要的自由输入，不强行伪造成选择题：路径、参考文件、水印文字、品牌规范、数量上限和预算值应由用户实际提供。
- “是否使用 image-gen”仅接受1使用（默认）和0不使用。使用时按该技能提供的渠道执行；不用时由用户选择方式，不检查或配置 image-gen。不要求普通用户选择接口模式、环境变量或CLI参数，不在问题表中展示或保存密钥。

## 提问顺序

任务开始提供参数文档，自动识别材料，采用明确起点或展示默认。需要配图时先完成讲义与结构分析，记录适用条件；`--check-config` 仅用于检查服务能力和非敏感配置，不覆盖用户表中的执行值。下表说明设计与执行条件，具体编号以模板为准；所有选填项均按明确答案、展示默认的顺序解析，只有缺值或冲突时才提问。校验后保存 `imgs/settings.md`，记录本任务的有效语义值及来源，编制完整配图审核稿；最终图数、任务数和生成范围在方案中确定，是否等待用户确认由审核开关控制。

统一技能还须先按 [field-management.md](field-management.md) 确认领域并加载完整专业配置，规划和审图使用所选领域的插图规则。领域选择与作图参数不互相替代。

### 视觉设计

| 参数 | 选择范围 | 条件与落实 |
|---|---|---|
| 预设 `preset` | 内容适配的预设／手动组合 | 阅读 [style-presets.md](style-presets.md)，说明每个预设的具体类型、风格和配色 |
| 类型 `type` | 沿用预设或推荐混合／信息图／流程图／对比图／框架图／时间线／场景图 | 阅读 [styles.md](styles.md) 的兼容性表；工具选项有限时只呈现当前适用候选 |
| 密度 `density` | 丰富覆盖／重点均衡／仅核心概念／按章节覆盖 | 对应 `rich/balanced/minimal/per-section`；不把它们绑定固定总图数；实际数量由知识需求与审核决定 |
| 风格 `style` | 沿用预设或推荐手绘／简洁扁平／工程示意等适用候选 | 按表内值确定沿用或覆盖；手绘区分 `sketch-notes` 与 `ink-notes` |
| 配色 `palette` | 沿用风格配色／黑墨语义配色／柔和配色／暖色／霓虹／自定义 | 阅读所选 `palettes/<名称>.md`，落实明确值或展示默认；自定义须有规范 |
| 图中文字 `language` | 中文／英文／中英对照或当前正文语言 | 落实有效值，语言选择不授权翻译整份讲义 |
| 比例 `aspect_ratio` | 按各图内容安排／统一横版／统一竖版／方图／自定义支持比例 | 自动安排也是用户选项；具体比例写进每张图的审核块，不为短平台额外生成一套图 |
| 参考图 `references` | 不使用／使用已有附件／补充文件 | 有真实文件才可作为直接参考；确认选用哪些文件 |
| 参考用途 `reference_usage` | 内容与布局／只参考风格／只参考配色 | 仅有参考图时问，对应 `direct/style/palette`；必要时每图分别确认 |
| 水印 `watermark.enabled` | 不加／添加 | 不加时文字、位置均标为不适用 |
| 水印文字 `watermark.content` | 使用用户已提供的名称／自定义文字 | 仅开启时问；没有真实名称时不能猜账号或默认作者身份 |
| 水印位置 `watermark.position` | 右下／左下／底部居中／右上 | 仅开启时问；不能遮挡坐标、标签和关键条件 |

### 生图结果与执行

本节模型、清晰度、质量、背景API值、格式、压缩、服务审核和图片信息展示选项仅在使用 image-gen 时适用；不用时这些固定选项不参与校验，其他工具按实际能力处理用户要求。设计、参考用途、变体、批量、数量预算、保存、审核和自检仍保留。image-gen的参考图16张/10MB及单候选限制不施加到其他工具。

| 参数 | 选择范围 | 条件与落实 |
|---|---|---|
| 模型 `model` | 沿用当前配置／更快的 flare／更精细的 sunburst／用户指定旧模型 | 推荐值明确映射到准确模型 ID；不能把“手绘”自动解释为升级高质量 |
| 清晰度 `resolution` | 当前配置／1K／2K／4K | 用自然语言解释用途，不宣称分辨率等同于准确性 |
| 质量 `quality` | 当前配置／低／中／高／更高或最高 | 采用本表有效值；`xhigh/max` 仅在用户明确选择且模型支持时使用 |
| 背景 `background` | 按设计配色／不透明／透明 | “按设计配色”不发送虚构 API 值；透明仅支持相应模型及 PNG/WebP |
| 格式 `output_format` | 服务默认／PNG／JPEG／WebP | 根据已选背景过滤不兼容选项 |
| 压缩 `output_compression` | 服务默认／参数值 70／参数值 90／自定义 0～100 | 仅 JPEG/WebP 时问；选择后记录实际整数，不凭模糊标签推定参数值 |
| 审核设置 `moderation` | 沿用服务默认／标准／服务支持的较宽松设置 | 未选调整时参数保持未设置；不承诺能绕过服务限制 |
| 每图变体数 `variants_per_image` | 一张／两个候选／用户指定数量 | image-gen直接参考图模式只能一张；其他方式按实际能力核对，图组总数与同图变体数分开确认 |
| 批量大小 `generation_batch_size` | 顺序生成／两张一批／四张一批／自定义 1～8 | 推荐四张一批；实际并行能力及服务限制优先，无法并行时说明后顺序执行，不增加任务数 |
| 图片信息展示 `show_info` | 不显示／显示图片信息 | 展示模型、实际分辨率、请求比例、已保存张数、质量、输出格式、背景设置、总耗时及输入/输出 token；缺失数值标注“未提供” |
| 数量或预算约束 `limit` | 按教学需求提出方案／设置图数上限／设置费用上限 | 选上限后请求实际值；无法可靠控制费用上限时说明限制，不能保证未知成本 |

清晰度、质量、格式等自然语言到具体参数的映射见 [image-backend.md](image-backend.md)。未知值、互斥组合和不支持的参数在生成前澄清；不用参数选择来更改正确知识。

### 文件与偏好

| 参数 | 选择范围 | 条件与落实 |
|---|---|---|
| 图片保存方式 `output_dir` | 课程目录的 `imgs/`／与配图文档同级／独立 `illustrations/`／自定义目录 | 保存位置变更后所有引用按文档位置解析，工作方案记录实际绝对路径 |
| 讲义处理 `article_action` | 保留原讲义并另存配图版／使用指定的新副本路径 | 默认保留原文；本流程不覆盖输入，不能为了照搬选项提供破坏原文的默认行为 |
| 已有图片 `existing_images` | 复用合格图并补充／新版本重新生成／暂不处理 | 仅目标目录已有图时问；不删除旧图，不把复用授权当作重画授权 |

全部默认值保存在本技能的 `config/extend.md`，仅由用户手动修改，旧路径兼容规则见 [default-settings.md](default-settings.md)。每次生成参数表时读取默认快照；选填空白采用已展示默认并记录来源。没有可用默认时补充本次答案，不据此更新全局配置。默认设置不包含接口、密钥、课程专属路径和授权。

## 记录与审核

`<任务名称>_参数.md` 是唯一用户填写表，固定五列；`imgs/settings.md` 是执行记录，保存稳定任务 ID、默认快照与来源、编号映射后的语义值、执行值、状态、条件和确认范围。状态为已选择、待回答、不适用；不适用说明原因，例如 PNG 不询问压缩。偏好更新只在会话中说明，不混入公开正文。

审核稿开头展示本次已选择的设计和生图设置，每张候选块包含 Type、Style、Palette、比例、语言、参考用途、水印、优先级及位置。审核时再次确认选用候选、实际插图数、变体数、正常生成请求数及限制；每图最多一次技术修正版的额外请求范围单独说明，用户的次数或费用限制优先。未知费用不得编造。

参数选择不等于人工批准方案。按 [workflow-switches.md](workflow-switches.md) 执行：方案审核1时，修改稿后等待当前方案确认；0时校验并留档范围后执行，不另追加人工批准。用户明确免于参数填写时仍记录有效参数与范围，必填空白或工具超时不构成该指令。使用 [task-state.md](task-state.md) 集中校验和保存证据。
