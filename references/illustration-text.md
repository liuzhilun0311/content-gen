# 图中文字与排版

用于全部新图提示词，独立于类型、风格和配色。目标是让可见文字与画面描述清楚分开，并给文字留出足够空间；这些约束不能保证生成模型没有错字，最后仍要实际看图。

## 原样文字白名单

在 `LABELS` 开头写明：“下面双引号内是必须逐字原样绘制的文本，不是画面描述词。仅绘制指定内容，不绘制外层双引号。不得改写、翻译、替换、增删字符，数字、标点、单位和大小写保持原样。”

每条可见文字单独一行，以 ASCII 双引号包围并指定用途或位置。包括标题、正文标签、图例、坐标刻度、公式、边界条件、底部结论和用户已开启的水印。示例：

```text
LABELS
下面双引号内是必须逐字原样绘制的文本，不是画面描述词。
仅绘制指定内容，不绘制外层双引号；不得改写、翻译或增删字符。
title: "时间、产能、收入分别衡量"
before: "每件4小时"
after: "每件15分钟"
formula: "240÷15＝16"
condition: "教学假设"
```

用途 ID 和 `LABELS` 等结构词不绘制。`ZONES` 通过 ID 引用文字，描述位置和关系；不可让场景描述、色名、色值或提示词指令混入图内。一个可见句子必须完整列入白名单，不能只引用其中的关键词。不同节点可使用同一文本，但要明确出现位置。

无文字图标的内部关系节点宜使用不含可见中文短词的对象 ID，例如 `source_document_object`；另行描述其对象含义并明确“不绘制节点 ID 或图标下说明文字”。模型可能把关系图中的中文节点名当作标签，即使 `LABELS` 没有列出。实际检查仍以白名单为准，多出的正确词语也不能自动追认为已批准文字。

把图标视为文字检查的一部分：仪表上的V/A、睡眠标记Z、屏幕刻度和循环符号，不因装饰用途而自动获得绘制许可。无必要时采用无文字图标；有教学意义时逐项纳入白名单和关系契约。涉及乘积、积分、速率和单位的标签应写清运算关系，不能为了缩短文字把“电压乘电流”改成含义不明确的“电压与电流”。

内容本身含双引号时用 JSON 字符串转义表示，并说明解码后的内容须保留内部引号，反斜杠不绘制。允许为适应框宽在词义边界换行，不允许丢字、替字或自动缩略。复杂公式优先保留在正文，图中只使用已核对的短关系式。

## 图面内容取舍

不在图面绘制“概念示意”“非实测数据”“仅供参考”“AI生成”等通用制作说明或免责声明，不将这些文字加入 `LABELS`。在 `AVOID` 明确禁止绘制；示意、实测、假设等来源性质仍在 `CONTENT` 内说明，明确它们是模型理解依据，不是默认可见文字。需要解释来源性质时，用相邻正文自然说明，不在图片上反复加通用标记。

与知识含义直接相关的单位、变量、坐标、适用条件和风险边界仍须保留。假设数字不能因为移除通用说明而变成实际成果：图面采用自然的“假设算例”等短标题或明确案例条件，正文也说明假设口径；图片离开正文后会被误解时，保留必要的具体条件。禁止为了图面简洁删除关键条件或把假设写成已发生的结果。

## 字体、字号与区域预算

每张提示词增加 `TYPOGRAPHY`，按实际类型填写以下设计目标，不引入新的用户必填参数：

- 字体：优先使用笔画清楚、结构规整、足够粗的中文字形。手绘风格采用整洁手写字形，避免草书和连笔；其他风格可写“思源黑体 / Noto Sans CJK SC 风格的清晰无衬线字形”。用户明确指定字体时在提示词记录，不声称已加载字体文件或精确匹配字体。
- 字号：以画布宽度 W 为基准，标题字高可先取 5%～7% W，主体标签 3%～4% W，必要注释不低于约 2.5% W，再按最长标签与节点数安排。以宽 1600 像素的设计参考，约为标题 80～112 像素、主体 48～64 像素、必要注释至少 40 像素。它们是排版目标而非接口硬参数，最终按返回尺寸和实际可读性核对。
- 区域：对文字承载较多的信息图、框架图和流程图，先给文字容器及其留白合计约 40%～55% 的画布面积；不是要求文字墨迹覆盖该面积。必须逐区说明位置和容量，图标为文字与关系服务。少量文字的场景图按实际需求分配，不机械占满一半画布。
- 标签：优先短词组，主体标签通常 3～10 个中文字符，较长标签分两行；单个区不堆长段落。不得为达到字数目标删掉必要单位、条件或改变概念。
- 留白：四周至少约 5% 安全边距，文字与框线留出内边距，行间和节点间有清楚间隔；不让箭头穿字，不截断最末行。

字号和空间发生冲突时，先删除无解释价值的装饰、增大文字区域、把冗长解释移到相邻正文；仍过密则提出拆图并按现有确认流程处理。不得以缩成小字、删掉专业条件或静默升级分辨率解决。

## 执行与看图

当前生图程序没有 `font`、`font_size`、`text_area_ratio` 等独立参数；只把排版要求写入完整提示词，不发送未支持字段。字体命名、双引号和区域预算都不能作为文字正确的证据。

保存提示词后核对所有可见文字已纳入带双引号的白名单，位置 ID 均有定义，没有多余标签或互相矛盾的字号要求。实际看图时逐项对照白名单，检查字符、数字、单位、标点、大小写、位置和阅读顺序；模糊小字先放大。关键文字仍无法辨认时视为未通过，不凭上下文猜测。

修正时保留原候选，另存提示词版本，优先减少文字密度和明确字形、位置；修改范围和付费调用仍遵守本任务已确认限制。不能以程序盖字、涂抹或裁掉条件来掩盖错误。
