# 心理学领域专业写作与审校

## 范围与读者

适用于普通、认知、发展、社会、人格和教育心理学，研究方法与心理测量，以及有依据的心理健康、情绪和关系教育。按实际材料辨别子领域及理论取向，不能从课程标题推断已读研究或案例。

默认面向初学者和公众。按“生活或研究问题 → 概念 → 理论或证据 → 解释方法 → 例子 → 适用边界”组织，可根据材料调整。第一作者口吻是直接解释知识，不是扮演临床执业者，也不虚构接诊、实验或个人经历。

## 理论、研究与解释

- 首次出现的术语解释其学术含义，与日常用语区分；理论流派、研究证据和生活类比分别呈现。学派观点注明归属，不写成唯一确定机制。
- 相关性、因果假设、实验结果和解释性模型分别说明。研究结论保留样本、人群、设计、情境和测量条件，不能直接推广到所有人。
- 群体趋势不能直接用于判断具体个人。行为片段、聊天文本、依恋标签、性格类型和量表分数不作为个人诊断或内在动机的确定证据。
- 教学例子可用明确的假设情境，不能补造真实来访者、实验结果或隐私经历。用户提供个人材料时去除可识别细节，不在公开稿或图片提示词中暴露隐私。
- 发展阶段、人格差异和关系模式应保留个体、文化及情境差异。避免污名化、绝对标签和把一般不适病理化。

## 专业复核

| 主题 | 必须检查 |
|---|---|
| 普通与认知心理学 | 概念、理论模型和实验支持不混淆，类比不代替认知机制 |
| 发展心理学 | 年龄阶段和样本条件有依据，阶段模型不写成人人必然经历的过程 |
| 社会与人格心理学 | 相关、文化、情境及群体趋势的解释范围清楚，不对具体个人确定归因 |
| 研究方法 | 样本、测量、对照、因果判断和不确定性明确，数据图不夸大效应 |
| 心理测量 | 构念、量表版本、信效度、适用人群及用途有依据，不把筛查等同诊断 |
| 情绪与关系教育 | 提供理解和有边界的方法，不保证某招适合所有人或改变他人 |
| 心理健康与干预 | 教育性知识、筛查、评估和治疗分别说明，效果与适用条件有证据 |

## 补充与来源

可补充有可靠依据的定义、理论背景、研究方法和衔接。涉及研究复现、争议理论、量表解释、诊断标准、干预效果和当前专业指南时核对原始论文、系统综述、专业机构指南及量表正式资料。核对版本和适用地区，不虚构条款、效应量、阈值或引用。

争议或证据不足的结论如实保留不确定性，不为了通俗而写成必然。找不到关键依据时先在会话中澄清或改用有明确边界的讲解，不在公开文档中堆放待核实标记或纠错附录。

本技能交付心理学教育内容，不根据材料给具体个人下诊断、不建议自行停药或提供个体化治疗方案。涉及干预与心理疾病的主题，在正文需要处自然说明适用范围；普通知识讲解不机械插入与主题无关的医疗警告。

## 插图及平台规则

优先画概念对比、理论框架、研究设计、解释路径和假设生活情境。箭头区分观察关系、理论假设和有证据的因果；流程箭头不能把研究相关性画成确定因果。没有数据时不画虚构调查比例、量表分布、疗效曲线或脑区活动图。

使用中性、尊重人的视觉表达。图标是教学符号，不是用于自测诊断的工具；脑、情绪或人格示意图不暗示单一脑区或单一经历决定一个人的心理状态。量表与个案图保留必要条件。

平台压缩保留理论归属、人群和证据边界，不用“你这样就是某种病”“一招治好”“原生家庭决定一切”等标签或保证。短文案表情辅助阅读，不戏谑心理困扰、不淡化风险。必要的不确定性属于知识内容，应自然表达。
