# 用户提问、文件填写与确认

需要向用户提问时读取本文件。领域选择、参数澄清和方案确认采用同一交互规则；参数编号与记录规范仍以 [parameter-rules.md](parameter-rules.md) 为准。

## 工具优先级

1. 优先使用当前智能体环境实际提供、当前模式允许且适合本次问题的内置用户输入工具，例如 `AskUserQuestion`、`request_user_input`、`clarify`、`ask_user` 或等效工具。工具出现在列表中不等于可调用；遵守工具用途、模式、选项数量及授权限制，不为提问擅自切换模式。
2. 没有可用工具时，若宿主允许文字选择题，发送带编号的纯文本问题，让用户逐题回复编号或答案。参数题沿用任务表编号，多个问题分别注明参数名称；确认题可提供“确认当前方案／修改后再确认／暂缓”等明确选项，不把修改意见当作批准。
3. 宿主禁止文字选择题或限制某类工具时，遵守该限制：提供参数文档供填写，必要确认采用宿主允许的简短直接问题。不得为了满足本技能的工具优先级而绕过宿主规则。
4. 同阶段已经具备信息、互不依赖的问题尽量合并一次调用；工具只支持单题时逐一提问，支持有限题数时按容量分轮。依赖前一答案的问题留到下一轮，不将尚未形成的审核方案与参数选择一起确认。

## 文件与会话的分工

| 事项 | 主要交互方式 | 保存方式 |
|---|---|---|
| 输入材料识别 | 自动判断上传文件、粘贴正文或本地材料；缺失时提醒上传 | 实际文件路径、哈希与格式记录在内部输入资料，不设用户参数 |
| 专业领域 | 与任务名称一起提问并展示实际可用领域；没有对应领域时在会话确认并先建立配置 | 答案同步到页首及领域行，已有领域编号绑定field_id |
| 任务名称 | 与专业领域一起提问；用户已提供名称时直接采用 | 名称原文同步到页首与名称行，无跨任务默认 |
| 本次任务起点、范围 | 起点选填，默认1；当前请求已明确则直接映射，不重复问；范围确需澄清时按工具优先级确认 | 参数表保留填写值，工作记录区分明确选择与默认来源 |
| 作图参数 | 交付五列参数 Markdown，用户在第四列填编号；补充澄清、条件参数或用户希望会话选择时按工具优先级提问 | 工具或会话答案回填同一张表，不另建冲突编号 |
| 自定义内容 | 用户通过会话或附件提供文字、路径、文件、数量或预算 | 转为内部supplements.json，公开模板不追加“补充修改”清单 |
| 配图审核方案 | 审核开关为1时交付稿件并按工具优先级确认方案；为0（默认）时规划留档并告知实际范围后直接执行，不问审核确认 | 工作记录保存方案版本、范围与审核模式，不把默认免审写成已人工审阅 |
| 实际图片审核 | 技能自检修正复检通过后，图片审核1时展示实际图组及对应位置，按工具优先级等待确认；0时直接插图和生成发布内容 | 记录图组文件、版本、哈希与确认范围；修改后的图组重新确认，已有当前有效确认不重复问 |

参数 Markdown 是每个任务必须生成的唯一用户填写表，也是选择记录；它不要求领域等确认只能通过编辑文件完成。用户在当前任务已明确回答的事项不重复问。工具选项受限时提供适用候选和自由输入入口，完整可选目录仍保留在参数文档；回答映射到表中稳定编号，不使用工具显示顺序替换编号。

提供用户确认的模板副本供填写，不改写其说明或加升级历史。填写完成后重新读取文件，校验并将原文留存在任务目录 `<任务名称>_参数.md`；输入、参数与补充资料分别绑定内部证据。

## 默认值与确认状态

- 首次使用先按 [default-settings.md](default-settings.md) 告知实际默认并提供 `config/extend.md` 可编辑链接；长期默认修改其中 JSON，本次差异填写生成任务表第四列。此环节只作说明，不使用选择题、不强制填写或确认；无调整要求时继续现有任务。
- 初始默认从 `config/extend.md` 的 JSON 读取；手动修改的新默认只在生成下一份表时映射展示，不覆盖已有任务快照。保存值显示为“默认”，不称为“推荐”。材料分析产生的建议可另行说明，不写成用户答案或领域默认。
- 不通过工具的预选项或默认答案机制替用户作出确认；工具强制使用“推荐”标记时，说明这是该工具的显示规则，技能保存值仍按“默认”记录。
- 必填项空白、工具无回答或超时不是接受默认；保持待确认，继续不依赖它的阅读与分析，停止依赖该答案的阶段。可选项按参数规范处理，不计入明确回答。
- “参数已填好”后实际重读文件并校验，不只凭会话声明认定齐全。会话新答案与文件旧答案冲突时，明确针对同一参数的最新修改优先；无法判断先后或意图时集中澄清，不猜测。
- 审核开关为1时配图审核是单独阶段确认，参数选择或修改建议不能替代当前方案确认。为0（默认）时按 [workflow-switches.md](workflow-switches.md) 记录免审模式、实际图数与范围后执行，不增加审核问题。免审不能跳过必填校验或扩展范围。
- 等待用户填文件时交付文件链接并说明待填写项；等待方案确认时交付审核稿及版本。用户回答后同步记录并接续任务，不重复询问已选平台是否还要生成。
