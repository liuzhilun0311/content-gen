# 内部保真审校与追溯

本文件用于指导一站式流程中讲义阶段的保真审校，不是交付模板。公开文档只输出内容正文，不输出待核实标记、纠错附录或单独的校对记录文件。用户后续明确要求记录时，再提供所需范围。

## 内部来源定位

优先使用原有时间戳、页码、章节及短引文。没有可靠定位时，可按原稿自然段或固定文本块建立内部编号；编号针对原稿，不针对重排后的正文。多文件同时记录文件名。

不得编造时间戳、页码、说话人、课程名称或引文。定位信息用于回查，不默认写入正文或另设附录。

## 纠错决策

| 情况 | 处理 |
| --- | --- |
| 同段明确定义或后文清晰复述足以确定错词 | 纠正，并在内部保留具体依据 |
| 常见术语近音，但上下文不足以唯一确定 | 可结合语境和可靠资料确认技术术语；仍无法确认时，用有依据的过程描述，不冒称恢复原话 |
| 数字、单位、公式疑似识别错，但没有直接依据 | 不按常识修正；保留原表达和必要限定，无法表达时简短询问 |
| 明确自我更正，例如“不是十，是十五” | 采用讲者明确的更正，内部记录修订依据 |
| 材料中的技术观点疑似错误 | 先核查，可靠依据充分时采用正确解释，内部记录依据；不能确认时澄清，不用转述口吻掩盖问题 |
| 两段陈述冲突且条件不足以解释 | 保留两种说法及其条件，不擅自裁决；不能清晰表达时询问 |
| 讲者指向未提供的图片、表格或演示 | 整理口头明确陈述，不重建未描述的图形和数据 |

“专业术语应该如此”本身不是充分的转写纠错证据。内部依据应对应实际语境或可靠核查；通用术语定义可以从可靠知识补充，但不声称恢复了未听到的原话。

常规标点、断句和删除口头禅不用逐条登记。概念性术语变化及数字、单位、公式修订需在审校时回查依据，不输出改动表。没有音频时，不声称核对了原声。

数字与单位既要保留数值，也要保留数量级、范围、对象和条件。不能将“大约”“百分之几”等模糊表达擅自精确化。必要的单位换写必须等值，不能改变精度；换算需实际核算并在内部检查。

## 自然表达不确定性

不使用“待核实”标签、疑点编号或校对批注。用内容自身的范围和措辞表达必要的不确定性，而不是用定论填补缺口。

- 原稿说“可能”，成品仍保留“可能”，不能改成“必然”。
- 来自某次试验的数值，保留“在该试验条件下”的范围，不能改成普遍关系。
- 术语可由上下文和可靠知识确认时直接使用；仍未能确认但过程已讲清楚时，直接说明该过程，不列错词与猜测词对照。
- 缺少图示时，只写口述支持的趋势，不写“本讲义未补图”等编辑说明。
- 公式不完整时，可在明确假设、变量和单位下补充标准方程；特定试验公式或模型拓扑不能确定时，不宣称已恢复原式。
- 两个数值矛盾时，内部保留差异并澄清对应条件；不能写成“原稿给出两个数值”暴露转换过程，也不能擅自择一作为定论。

## 知识补全与作者表达

在保持主题、核心信息和实验事实的前提下，可以补充以下内容：

- 缺少的术语定义、符号和单位解释。
- 论证所需的常规原理、数学关系与中间步骤。
- 自足阅读所需的背景、指代对象和概念衔接。
- 依据可靠资料确认的技术纠正。
- 用于理解的假设性例子或标准简化模型，明确其条件。

不允许补造特定样品参数、某次试验数据、图示拐点、未提供设备的真实配置、最优工程设定、人物经历或作者亲自完成的实验。缺失视频不能成为编造视觉信息的理由。

先用全文上下文判断缺口，再选择必要知识补充，不让扩写挤掉原有知识点。基础知识可以采用有把握的通用知识；专业、易混淆、涉及安全或可能变化的内容按适用规则查权威一手资料。信息不足时采用有条件的标准解释或简短澄清，不能凭“丰富经验”定案。

公式补充须说明变量、单位、正负号约定、边界条件和模型假设。新模型可以作为明确的简化模型引入，不能伪装成未提供图示的复原。知识补充导致技术观点修订时，内部核对依据和对全文的影响，不覆盖原始附件。

成品直接解释知识关系，不写“原稿未解释，因此补充……”。研究材料可保留研究自身的条件，不能虚构“我测得……”或“我们研究证明……”。具体例子读取本领域写作示例。必要引用是正常知识来源，不是转换说明，应按适用要求保留。

未提供图示不等于相关口述均不可用。原稿明确说出的数值或趋势可以保留；未描述的坐标、曲线形状、结构和数值不能猜测。

## 长稿覆盖台账

按主题边界分段，保留相邻段必要上下文。内部记录知识单元、来源、关键数值与条件、成品去向，以及已保留、已合并或待处理等状态。

另维护术语一致性与未解决问题，避免后半稿重定义概念或将前半稿的不确定性覆盖为定论。普通短稿不必创建复杂中间文件；内部工作记录不默认交付。

每轮续写记录已处理范围与下一段起点。最终从原稿回查知识单元，而不只在生成文本中寻找遗漏。完整讲义不能以“按文体省略”为由删除有信息量的内容，也不能为了后续平台发布而提前缩减；讲义通过审校后才由主入口继续配图和平台生成。

工具输出截断、提取失败或上下文容量不足时，继续读取遗漏范围或在交付消息中说明限制。不能把只看过的前几页称为全文。表格、公式乱码不自信补全；核心内容不可用时先澄清。

## 外部核查

围绕当前主题查缺补漏，不为文风扩写一套新教材。补充内容需要核查时，优先使用权威一手资料，并按适用要求给出必要引用；不另设“原稿与补充对照”或校对附录。

外部来源证明某种说法正确，不必然证明讲者说的是那个词。内部区分材料事实、纠错判断、通用补充与假设性例子，正文可融合为作者叙述，但不能把补充冒充特定试验事实。未核查时不暗示已核查；必要核查无法完成时，在交付消息中简短说明，不添加正文校对标签。
