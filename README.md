# 内容创作 (content-gen)

将课程、技术说明、学习资料或已有文章整理为知识完整的内容，规划共享插图，并按独立开关生成阅读版和五个平台的发布素材。

英文调用标识是 `$content-gen`，界面显示为“内容创作 (content-gen)”。

## 适用场景

- 从原始文字材料开始，整理讲义、规划配图并制作发布内容。
- 保留已经完成的正文，只规划插图或接续生成图片。
- 使用已有配图方案、生图结果或配图正文，继续尚未完成的阶段。
- 只制作阅读版，或只生成指定平台的素材，不强制重新执行整套流程。

## 安装与准备

将完整的 `content-gen` 目录放入宿主支持的用户技能目录，不要只复制 `SKILL.md`。
Codex 使用 `$CODEX_HOME/skills`，未设置时通常为 `~/.codex/skills`；按宿主方式刷新技能。

需要能够读取本机文件的智能体，以及实际阶段使用的 Python、Node.js、文档导出和浏览器能力。
具体可用工具由 [环境预检](references/reliability-tools.md) 检查，文件存在不代表依赖已经安装。
涉及生图时默认使用已安装且已配置的 `$image-gen`；选择不使用时，按用户指定方式处理，不借用其他技能的凭据。

## 输入

支持粘贴文字、TXT、Markdown，以及能够实际提取正文的 Word、PDF。
音视频需要先提供文字转写，本技能不会凭文件名编造内容，也不自动扫描视频目录。

任务开始后会读取材料，询问任务名称和专业领域，并生成五列参数填写文档。
任务名称由用户决定；选填项可以沿用本次表中已经展示的默认值。

| 起点 | 需要准备 |
| --- | --- |
| 1. 原始内容 | 需要整理或教学重构的文字材料 |
| 2. 已转换或无需转换的内容 | 希望保留的完整正文 |
| 3. 配图方案 | 正文及已有配图规划 |
| 4. 生图 | 正文、确定的方案及适用参数 |
| 5. 正文插图和发布内容 | 正文及已生成、可读取的图片 |

## 调用示例

以下是在智能体对话中使用的请求，不是终端命令；材料路径需替换为实际文件。

```text
使用 $content-gen 处理我上传的课程文字稿，先读取材料，
再让我确认任务名称和专业领域，并生成任务参数表。
```

```text
使用 $content-gen 保留这篇文章的正文，只规划配图，
本次先不调用图片服务，也不生成平台稿。
```

```text
使用 $content-gen 根据已有正文和图片，从起点 5 接续，
只输出 content 阅读版和微信公众号文章。
```

## 输出

任务默认保存在当前工作目录的 `outputs/<任务名称>_<时间>/`，已有任务续接时沿用原目录。
按所选起点和输出开关，可能包含：

| 输出 | 形式 |
| --- | --- |
| 基础正文与配图正文 | Markdown，保留必要的审核和任务工作资料 |
| 共享封面与内容图片 | 图片文件、提示词和内部执行记录 |
| content 阅读版 | 含目录和图片的 HTML、EPUB、PDF |
| 知乎文章 | DOCX 和引用原图 |
| 微信公众号文章 | 复制排版 HTML 和引用原图 |
| CSDN 文章 | 复制排版 HTML 和引用原图 |
| 抖音、小红书素材 | 各自的标题、文案、标签 Markdown，以及精选原图 |

各平台直接依据共同正文和图组独立成稿，不把另一平台文章当作默认底稿。
content 阅读版保存到 `publish/content/<任务名称>/`，平台成果位于各自的 `publish` 子目录。

## 配置与审核

- [config/extend.md](config/extend.md)：长期默认值及选项说明；默认值以其中的 JSON 为准。
- [参数规则](references/parameter-rules.md)：本次填写表、条件选项和已有任务兼容规则。
- [生图衔接](references/image-backend.md)：选择是否使用 `image-gen` 及执行边界。
- [输出开关](references/workflow-switches.md)：各项输出和两类审核开关。

长期默认值与单次任务选择分开，本次选择不会自动成为下次默认。
生图凭据由实际图片工具的私有配置管理，不写入参数表或成品。
审核开关只控制是否等待人工确认，不会取消技能自身的图片检查。

## 能力边界

不自动登录、发布或上传到内容平台，不覆盖输入原件。
付费生图需要对应授权；失败或状态不明时，不通过反复调用来猜测结果。
缺少依赖、材料或确认时，会说明尚未完成的阶段；文件已生成不等于专业审校和导出验收已经通过。
复制排版页面通过本机检查，也不等于目标平台编辑器已经完成粘贴验证。

详细执行规则见 [SKILL.md](SKILL.md)。
